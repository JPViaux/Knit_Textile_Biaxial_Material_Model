# Publication package v1.0.0

Data and code accompanying *A hyperelastic material model for weft-knitted textiles under biaxial tension calibrated across four knit architectures*, by Juan Pablo Viaux, Caitlyn MacKay, Ihsan Uluturk and Scott E. Stapleton.

Includes four experimental specimens, the final SV_exp_polycon_mo model, calibration/component/greedy workflows, 44 compiled paper inputs, 188 archived fits with original batch snapshots, metadata provenance, citation metadata, a pinned environment and a SHA-256 inventory of code and data.

The selected Purl 0:1 curve uses the S02 publication label while preserving its original S01 source identity and unchanged quality flags. See the data guide. Full production optimization campaigns were not repeated during packaging. Windows validation and reproduction limits are documented in 2_Code/VERIFICATION.md.

Code/data licenses and Zenodo archival remain pending the authors' decision. This release has no assigned archive DOI.

The publication catalog exposes only the four shipped raw datasets and final model. One canonical greedy report serves Figures 8 and 9. New figures, calibration results, campaign cases and derived batches are isolated under generated; the archive index and root guide identify the main reproduction routes.

# Final material model

SV_exp_polycon_mo.f and model.json define the sole released model. Both are unchanged scientific source files. The registry is adapted to discover them here. Parameter initial values, types, bounds, and fixed/free flags are in ../inputs/Material_Parameters/SV_exp_polycon_mo, grouped by architecture. Use the numbered calibration or verification entry point to compile the UMAT and pack its named parameters.

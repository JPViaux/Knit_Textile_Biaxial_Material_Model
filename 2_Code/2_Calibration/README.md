# Calibration

Select CASE_FILE in separable_solver_fit.py and run from VSCode. Direct case files and parameter bounds are under ../inputs. Published fit artifacts are under ../archived_results. Fresh fitting outputs go to ../generated/results/calibration_refitting. Plot scripts use the bundled final fits and measurements and save figures under ../generated/figures.

See the [repository guide](../../README.md) for setup, scope, and verification.
